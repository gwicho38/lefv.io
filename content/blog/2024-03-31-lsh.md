Started [lsh](https://github.com/gwicho38/lsh) today. It syncs `.env` files between my machines — encrypted, with no account and no server in the middle.

The problem is dull and constant. There are secrets on the laptop that the desktop needs. Copying them across by hand is how a key ends up pasted into a chat window, and every hosted answer wants a subscription, a tenant and a login (and a seat, and a plan) before it'll hold four lines of text.

So: encrypt locally with AES-256, address the result by content, and publish it over IPFS under a name derived from the shared key. Any machine holding that same key pulls the latest version. There's nothing to sign up for, because there's nobody to sign up with.

One trade-off I went in knowing — the encrypted content sits on the machine that pushed it and is served peer to peer, so "pull anywhere, anytime" needs a pinning service behind it. Acceptable for now.

```bash
lsh push
lsh pull
```

That's the whole interface I wanted.
