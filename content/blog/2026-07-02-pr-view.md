## Why Our Work is Harder Now

A constant theme (at least for me) of post-AI Software Engineering is that it is *Icarian* and *quixotic* (the more things change …). It's therefore my opinion that as capability goes up (we can now specify/implement computer programs with ease) complexity must go down.

> The upshot is that program definition interfaces should move *closer* to first principles (let's get back to building with primitives, loops and functions only!) and that production software definitions should be smaller, more rigorous, must be traceable, and must be testable.

The tension here is that while I want to preserve the axiomatic rigidity described above, there's an equally valid force pulling towards more entropy and code with less rigor simply for the fact that "we all got to eat." Making "80% progress" can now be accomplished by churn and churn gets us fed. This is honestly great, and I think preferred to an outcome where we have rigor but no food.

We live in the churn world for now, and that's fine, but that means that the cognitive load we are all under is super high. To me it's meant that reviews, contemplation, and cognition are very very expensive, since they tax the 80% progress and our ability to eat food now. So my (in progress) solution is that we should do more to make cognition easier, and that cognition is easier when information is compartmentalized.

## How PR View Has Helped Me

One attempt that so far has proven useful to my overall software process is to apply this solution to the PR review process, and therein lies PR View.

I've written no code in PR View itself, I don't care to right now anyway. Instead, PR View is a tool that I'm using to slow myself down when performing PR reviews, increase information density (I'm seeing more comprehensible stuff per unit reviewed), and actually try and provide feedback that goes beyond — I checked on my own claude instance and it said this looks good (and I reviewed that).

## Why Did You Do This?

If you (we) have made it this far then you may share this question with me. How is it possible that in the known universe, this solution doesn't exist (and better)?

Here's a screenshot of the results of just typing PR Reviews into a search engine.

![Search engine results for the query "PR Reviews", showing a page of competing tools](/images/pr-view-search-results.webp)

My current answer is that:

1. a lot of the compelling tools out there cost money, and
2. the tools review the PRs but don't help me think more clearly about the content reviewed.

So maybe it's a throwaway or not, but the thrust certainly isn't. Cognitive load is at its zenith, and it is getting worse every day, that is, unless we do something about it.
