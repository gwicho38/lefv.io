Started [mitodo](https://github.com/gwicho38/mitodo) today. It's a rewrite of [eilmeldung](https://github.com/christo-auer/eilmeldung) by Christopher Auer, pointed at a different problem, and it inherits his GPL-3.0.

The format was never the thing that needed fixing. Markdown checklists are the most portable todo format there is — every editor reads them, every agent reads them, and they outlive whatever tool I abandon next. What they lack is a fast way to *work* them: filtering, jumping between projects, ticking something off without first hunting for the line.

So mitodo is that layer and nothing more (the moment it grows a database, I've lost the plot). It reads a directory of `TODO.md` files, shows them in a three-pane TUI with vim keybindings and a query language (`/pri:P0 !done`), and writes changes back to the source markdown without reformatting it.

No database, no import step, no proprietary format. The files stay editable in my editor, from a script, and in the TUI — at the same time.

The name is Spanish. *Mi todo*, "my everything", which happens to contain the word "todo".
